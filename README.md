# RetroTape Web

Simulador web de toca-fitas retrô.

## Estado atual
- biblioteca de cassetes;
- lado A/B;
- play, pause, stop, anterior, próximo, rewind e eject;
- carretéis e VU meters animados;
- volume;
- áudio demonstrativo gerado no navegador via Web Audio API;
- responsivo para celular e desktop.

> O tom demonstrativo serve apenas para validar o mecanismo. Músicas comerciais não são incluídas sem licença.

## Estrutura
- `index.html`: interface semântica;
- `styles.css`: visual responsivo;
- `app.js`: estado e motor do player.

## Teste
Abra `index.html`, escolha **Demo Vintage**, pressione **PLAY** e permita áudio no navegador caso solicitado.
